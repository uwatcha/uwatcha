#### 🪙 CoinRoguelike - ローグライクゲーム制作 (2026)
  コイントスで戦うターン制ローグライクゲームをUnityで制作。[unity1week「うら」](https://unityroom.com/unity1weeks/101) に応募。  
  友人3人のチームで制作し、私はプログラミング、他の2人はそれぞれプランニング&UIデザインとキャラクターデザインを担当しました。  
  表と裏の2つの「面」を組み合わせてコインを作り、コイントスで出た面の効果（攻撃・回復など）で敵と戦います。片面ごとの「重さ」で、表裏の出やすさが変わるため、どの面を組み合わせるかが戦略になります。敵を倒すと新しい面が手に入り、洞窟を進むほど敵が強くなります。
  * **使用技術**: `Unity` `C#`
  * **リポジトリ**: [DiverWorlds/CoinRoguelike](https://github.com/DiverWorlds/CoinRoguelike)
  * **成果物 (Unityroom)**: [プレイする](https://unityroom.com/games/thecoinwizard)

#### 🧱 BREAKDOWN - ブロック崩し×シューティングゲーム制作 (2022)
  授業の課題で制作した、ブロック崩しにレトロなシューティングゲームの要素を取り入れたオリジナルゲーム。授業で習った内容に加えて、友達から自主的に教わりながらオブジェクト指向も取り入れて実装した、初めてのゲーム作品です。  
  ボールとショットで敵を倒し、敵の弾を避けながらステージを進みます。ショットは直進するため当てやすいが、攻撃力が低い。ボールは当てにくい分攻撃力が高い。2つを使い分けながら攻略するゲームです。ステージによって、敵が迫ってくることがあります。
  * **使用技術**: `Processing`
  * **リポジトリ**: [uwatcha/BREAKDOWN](https://github.com/uwatcha/BREAKDOWN)

### 🤖 Built with AI (Claude Code)

#### 💰 Kakeibo - 個人用家計簿アプリ (2026~)
  自分の生活に合わせた家計簿アプリを、AIコーディングエージェントの Claude Code を使って開発。  
  収支や口座の記録に加えて、カードや銀行のメールからの自動記録、レシートや決済画面の写真の AI 読み取り、家計についての AI 相談、ホーム画面のウィジェットなどを備えています。Android と Web（PC）で使えます。
  * **使用技術**: `Expo` `React Native` `TypeScript` `Supabase` `Claude API` `Claude Code`
  * **リポジトリ**: [uwatcha/Kakeibo](https://github.com/uwatcha/Kakeibo)

#### 🎵 MusicLabelAutoAssigner - 音楽ライブラリの自動ラベル付けシステム (2026)
  Mac のミュージック（旧 iTunes）の曲に、Claude API の判断でラベル（ジャンルや「歌」「アニメ」など）を自動で付ける AppleScript を、Claude Code を使って開発。  
  トークンの消費量を抑えるため、曲名やメタ情報から判断 → モデル内の知識からの判断 → Web 検索による判断、の3段階でラベル付与を行なっています。  
  定期実行で新しく足した曲にも自動で付き、手で直したラベルは書き換えません。
  * **使用技術**: `AppleScript` `Claude API` `Claude Code`
  * **リポジトリ**: [uwatcha/MusicLabelAutoAssigner](https://github.com/uwatcha/MusicLabelAutoAssigner)
